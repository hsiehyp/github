🚀 網站 ZIP 一鍵發布

完全靜態 HTML + JavaScript，可直接部署於 GitHub Pages。ZIP 在您的瀏覽器解壓縮，網站檔案直接提交到您的 GitHub Repository。

安全提醒：請只使用權限受限的 Fine-grained Personal Access Token。Token 僅保留在本頁記憶體，不會存到 localStorage。請勿使用來路不明的網站或共享電腦操作。GitHub Pages 公開網站請勿包含私人資料。

需要 Repository 建立權限（若建立新儲存庫），以及目標儲存庫的 Contents: Read and write、Administration: Read and write（設定 Pages）。如需啟用 Actions 部署，可能還需要 Workflows 權限。本工具使用 branch 部署。

ZIP 須包含 index.html，可包在單一最外層資料夾內。限制：壓縮檔 25 MB、解壓總量 50 MB、單檔 20 MB、最多 500 個檔案。請避免大量影片。
